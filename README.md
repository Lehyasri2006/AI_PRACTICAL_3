# Aquaguard AI DLS

## Practical 3 - Artificial Intelligence Lab

### Project Description
Aquaguard AI DLS is an AI-based water tank management system that uses Depth-Limited Search (DLS) to find a sequence of actions to reach a target water level.

### Algorithm
Depth-Limited Search (DLS)

### Actions
- FILL_100
- FILL_200
- DRAIN_100
- DRAIN_200

### Technologies
- Python
- Artificial Intelligence
- Search Algorithms

### Main File
algorithms/dls.py

### How to Run
python algorithms/dls.py
